# Chat No Fade
If you're annoyed about strange fade in chat, while you trying to read old chat cards, this module for you!
It's erasing this annoying mask from chat, makes him readable anywhere you're scrolling.

# Installing
Manifest download link: `` https://github.com/p4vl0-dev/chat-no-fade/releases/latest/download/module.json ``
# Compatibility
Supports FoundryVTT v13+ (In v14 it's no need, because it's bug from v13 only)
